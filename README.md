# Movilidad-urbana-y-productividad-econ-mica-en-ciudades-LATAM

El análisis contiene 2 datasets "tomtom_traffic.csv" que incluyen 1,004,464 registros en los cuales se contiene información sobre niveles de tráfico y congestión en tiempo real en distintas ciudades monitoreadas. Cada registro corresponde a una actualización puntual del estado del tráfico en una ciudad.
Dataset "oecd_city_economy.csv" que incluye un registro de 30 países con indicadores anuales sobre economía urbana, empleo, contaminación y población recopilados por la Organización para la Cooperación y el Desarrollo Económico.

**Contenido del repositorio:** Notebook principal con limpieza, identificación de registros de 2024, cálculo de promedios de tráfico por ciudad, indicadores económicos, visualización relacional economía-tráfico y conclusiones.

**Cómo reproducir el análisis:** Abre notebooks/S5 Urban_Mobility_Economic_Productivity.ipynb Ejecuta las celdas en orden. El notebook carga automáticamente el dataset desde /data/ o desde un enlace público (según corresponda).

**Objetivo del análisis:** El objetivo es generar una base limpia, estandarizada y lista para futuros análisis sobre cómo la movilidad urbana puede influir en la productividad económica.
